# Bluetooth Controller

Use Unity Input System as the first-line controller abstraction.

Required actions:
- Steering
- Throttle
- Brake
- Nitro
- Handbrake/Drift
- Camera
- Pause
- Menu navigation

UX:
- Connected notification
- Disconnected notification
- Reconnect without restarting the race when possible
- Controller mapping screen
- Do not confuse Bluetooth gamepad input with Bluetooth audio routing
