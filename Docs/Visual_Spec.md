# Visual Specification — Neon Rush Racing

## Palette
- Background: near-black
- Primary accent: electric cyan
- Secondary accent: electric blue
- Optional accent: restrained violet
- Text: white / cool gray

## UI
- 16dp outer padding on mobile
- 12–16dp section spacing
- 14–18dp card radius
- 44–48dp minimum touch target
- 22–26dp normal icons
- 28–32dp primary action icon
- Dark translucent panels with subtle borders
- Neon glow only on active/important states

## Main Menu
3D car centered, cinematic garage background, player level/currency top-right,
RACE as the primary CTA, Garage/Cars/Events/Settings secondary navigation.

## Garage
Large 3D car preview, rotate/zoom, stats panel, Upgrade and Customize actions.

## Race HUD
Position + lap at top, minimap in a corner, speed/RPM/gear near bottom,
steering/brake/accelerator controls, nitro, pause. Keep the road visible.

## Icon style
Use clean white vector line icons with consistent stroke weight and no dark outline.
Active states may receive a subtle cyan neon glow.
